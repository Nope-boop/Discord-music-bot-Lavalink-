# 🎵 Music Commands Directory

Welcome to the `commands` folder! This directory contains all the executable commands for the Discord music bot. 

## 📂 Folder Structure

Since the commands are simple and straightforward, they are kept in a clean, flat structure so everything is easy to find:

```text
commands/
├── play.py       # Joins the channel, searches, and plays a track
├── skip.py       # Skips the currently playing song
├── stop.py       # Stops playback, clears the queue, and disconnects
├── queue.py      # Displays the upcoming songs
├── volume.py     # Adjusts the playback volume
└── README.md     # You are here
